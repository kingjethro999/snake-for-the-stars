Back then, a small group — **THE STARS** — set out to build this. Life, and later the pandemic, pulled everyone apart before it shipped. This repo closes that chapter: Snake, in BASIC, the way we meant to finish it.

## Play

Requires [FreeBASIC](https://www.freebasic.net/) (`fbc`) or [QB64](https://qb64.com/).

```bash
fbc -s console snake.bas
./snake
```

### Controls

| Key | Action |
|-----|--------|
| `W` `A` `S` `D` or arrows | Move |
| `P` | Pause |
| `Q` | Quit |

Eat the food. Don't hit the walls. Don't bite yourself. Score climbs; speed rises.
